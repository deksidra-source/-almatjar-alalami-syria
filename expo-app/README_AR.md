# نموذج المتجر العالمي سوريا — Expo

هذه نسخة Expo تجريبية مستقلة تمامًا، وتعيش داخل المجلد `expo-app/`. أُبقيت نسخة Flutter الأصلية داخل `mobile/` دون حذف أو استبدال.

## اللغات

يدعم النموذج العربية والتركية والإنجليزية والصينية واليابانية. اضغط زر `文 A ع` في أعلى الشاشة لاختيار اللغة. تتحول العربية تلقائيًا إلى اتجاه RTL، بينما تستخدم التركية والإنجليزية والصينية واليابانية اتجاه LTR.

## ما يمكن تجربته

يمكن للمستخدم تصفح الصفحة الرئيسية، البحث في المنتجات، التصفية حسب الأقسام، فتح تفاصيل المنتج، إضافة المنتجات إلى السلة، رؤية سعر المنتجات والشحن منفصلين، اختيار التوصيل إلى الباب أو نقطة استلام شريكة، وكتابة أقرب نقطة دالة. تُحفظ السلة محليًا عبر AsyncStorage لتبقى متاحة عند ضعف الشبكة. يمكن اختيار الدفع عند الباب أو الدفع اليدوي بين البائع والمشتري، مع عرض التسوية اليدوية بين البائع والإدارة. كما يمكن فتح صفحة المتاجر وتجربة غرفة المتجر الصغير وغرفة المتجر الكبير، واختيار نوع الإعلان المروّج لمدة ثابتة مقدارها 7 أيام بسعر مرجعي قدره 1 دولار للمتجر الصغير و10 دولارات للمتجر الكبير. تتضمن النسخة أيضًا لوحة إدارة تجريبية تقبل أو ترفض طلب الترويج وتظهر إشعارًا محليًا، وتبويب دعم مباشر، ومساعد القط الطائر، وبطاقات تفاعلية للبحث بالصور وتجربة الألوان وفيديوهات التسوق والشراء الجماعي. هذه الأخيرة واجهات تجريبية؛ تشغيل الكاميرا والفيديو والذكاء الفعلي يحتاج صلاحيات وموردًا أو خدمة خارجية قبل الإنتاج.

الدفع الإلكتروني غير مفعّل. الدفع اليدوي هو الخيار التجريبي الوحيد، بينما يظهر Sham Cash وiCash كخيارات «قريبًا». البيانات الحالية للعرض فقط، ولا تمثل منتجات أو متاجر حقيقية ولا مراجعات مستخدمين.

## التشغيل من الهاتف

ثبّت تطبيق **Expo Go** من المتجر المناسب لهاتفك. بعد رفع مجلد `expo-app` إلى GitHub أو فتحه في بيئة Codespaces، شغّل الأوامر التالية من داخل المجلد:

```bash
pnpm install
pnpm start
```

سيظهر رمز QR في شاشة Expo. افتح Expo Go واضغط خيار مسح QR، ثم امسح الرمز. يجب أن يكون الهاتف وبيئة التشغيل على شبكة تسمح بالوصول إلى خادم Expo. وللمعاينة من المتصفح يمكن استخدام:

```bash
pnpm run web
```

## الفحص

يُستخدم الأمر التالي لفحص TypeScript:

```bash
pnpm run typecheck
```

هذه النسخة واجهة تجريبية محلية. تسجيل الدخول عبر الهاتف والرمز المؤقت، قاعدة PostgreSQL، الإشعارات الفعلية، رفع الصور، المخزون الحقيقي، وقرارات الإدارة المتزامنة ستُربط بالـ API الخلفي قبل الإنتاج.
