# خارطة تحويل المتجر العالمي سوريا إلى منصة إنتاجية

## الهدف

يُطوَّر المشروع كسوق إلكتروني متعدد البائعين مستقل يحمل هوية «المتجر العالمي سوريا»، ويستفيد من الأنماط الناجحة الظاهرة في منصات مثل Trendyol وHepsiburada من حيث اتساع الكتالوج، وضوح التصنيفات، البحث والفلاتر، العروض، صفحات المنتج، السلة، تتبع الطلب، ومساحات التجار. لا يُنسخ أي اسم أو شعار أو محتوى أو كود أو تصميم محمي، ولا تُستورد بيانات منتجات حقيقية من تلك المنصات.

## النطاق الوظيفي المستهدف

### تجربة المشتري

تتضمن النسخة الإنتاجية تسجيل الدخول الآمن، الصفحة الرئيسية، تصنيفات متعددة المستويات، البحث النصي، الفلاتر حسب السعر والمحافظة والشحن والتوفر، صفحة المنتج، صور متعددة، المتجر والبائع، المفضلة، السلة، القسائم، العناوين، اختيار التوصيل إلى الباب أو نقطة استلام، فاتورة تفصل المنتج والشحن والجمارك ورسوم الخدمة، إنشاء الطلب، الدفع المعتمد، التتبع، الإشعارات، الدردشة المرتبطة بالطلب، الإرجاع، والتقييمات بعد تحقق من عملية شراء حقيقية.

### تجربة التاجر

تتضمن تسجيل التاجر والتحقق من الوثائق، إنشاء المتجر، إدارة المنتجات والصور والمتغيرات والمخزون، سياسات الشحن، استقبال الطلبات، تحديث الحالات، التقارير، الاشتراك، طلب الإعلان المروّج، ومراجعة الأداء. يجب أن تكون كل عملية محمية بصلاحيات الخادم، لا بإخفاء عناصر الواجهة فقط.

### لوحة الإدارة

تتضمن مراجعة التجار والمنتجات والبلاغات، إدارة المستخدمين والأدوار، مراجعة الطلبات والمنازعات والإرجاعات، إدارة الشحن، إعدادات الاشتراكات، إعدادات الإعلان المروّج، سجل التدقيق، ومؤشرات التشغيل. أسعار الإعلان المروّج إعدادات قابلة للتغيير من المدير وليست ثوابت داخل الكود؛ كل طلب يحفظ السعر الذي كان نافذًا لحظة إنشائه.

## مراحل التنفيذ

| المرحلة | الناتج | شرط الانتقال |
|---|---|---|
| 1. الأساس الآمن | مصادقة OTP، جلسات، أدوار، PostgreSQL مُدار، هجرات، أسرار آمنة | اختبارات صلاحيات ناجحة وعدم وجود مسارات إدارية عامة |
| 2. الكتالوج والتاجر | منتجات، صور، مخزون، فئات، متجر، بحث وفلاتر | اختبار ملكية التاجر وتحديث المخزون |
| 3. السلة والطلبات | سلة خادمية، فاتورة، عناوين، شحن، حالات طلب | اختبار المخزون والتكرار والتراجع |
| 4. الدفع والتسوية | مزود معتمد، دفع يدوي مضبوط، استرداد، سجل مالي | اعتماد قانوني وتقني وبيئة اختبار |
| 5. الإدارة والثقة | بلاغات، مراجعات موثقة، إرجاع، منازعات، إشعارات | سجل تدقيق واختبارات إساءة الاستخدام |
| 6. التطبيقات والنشر | تطبيق هاتف إنتاجي، متجر ويب، CI/CD، مراقبة، نسخ احتياطي | اختبار أجهزة حقيقية ومراجعة الخصوصية والمتاجر |

## ضوابط عدم الادعاء بالجاهزية

الواجهة التجريبية لا تُعد متجرًا إنتاجيًا، ولا تُعرض منتجات أو مراجعات أو أسعار وهمية. لا يُفعّل الدفع أو الشحن أو الذكاء الاصطناعي أو التاجر الخارجي قبل توفير الحسابات والاعتمادات والسياسات والاختبارات اللازمة. يجب أن تبقى أسعار الإعلان غير محددة حتى يضعها مدير مصادق عليه من لوحة الإدارة.
