# حدود مشروع المتجر العالمي سوريا

## القرار المعتمد

«المتجر العالمي سوريا» مشروع مستقل بالكامل عن «سوقنا سوريا». لا تُعاد مشاركة قاعدة البيانات أو جلسات تسجيل الدخول أو مفاتيح النشر أو النطاقات أو ملفات المصدر أو سجلات المستخدمين بين المشروعين.

## ما تم التحقق منه

تم فحص الحزمة الحالية بحثًا عن أسماء المشروع السابق ومعرّفاته ومراجع نطاقه، ولم تظهر مراجع تشغيلية إلى «سوقنا سوريا». بقيت الحزمة الحالية نموذجًا ثابتًا مستقلًا، بينما يظل الربط الخلفي والموبايل الحقيقيان ضمن مرحلة لاحقة.

## قواعد التغيير اللاحق

أي إنشاء لتطبيق Flutter أو بوابة React/Next.js أو خدمة Node/NestJS يجب أن يستخدم أسماء حزم ومفاتيح بيئة وقاعدة بيانات خاصة بهذا المشروع. لا يجوز نسخ أسرار أو جلسات أو جداول أو بيانات مستخدمين من المشروع السابق.

لا يُفعّل التاجر الخارجي أو الدفع الحقيقي أو الاشتراك المدفوع قبل اكتمال المصادقة، والهجرة الآمنة، واختبارات الصلاحيات، ومراجعة الشروط والامتثال، وتوثيق وسيلة الدفع القانونية المتاحة.

## سياسة الدفع الحالية

الدفع اليدوي هو الخيار المفعّل حاليًا للإعلانات المروّجة والاشتراكات المرجعية، ولا يؤدي إرسال الطلب إلى تفعيل الإعلان تلقائيًا. يظهر خيارا **Sham Cash** و**iCash** في الواجهة كخيارات مؤجلة وغير قابلة للاختيار، إلى حين توفير حسابات تاجر مستقلة، ومواصفات API، وبيئة اختبار، وآلية تحقق من العملية، ومراجعة قانونية قبل فتحهما للمستخدمين.
