# ميزات الذكاء الاصطناعي — خطة تفعيل لاحقة

## مساعد المشتري

يُخطط لمساعد محادثة داخل التطبيق يساعد في البحث عن المنتجات، مقارنة المواصفات، تلخيص سياسة الشحن، وتحويل سؤال المشتري إلى استفسار للمتجر. لا يقدم المساعد وعودًا عن الجودة أو الجمارك، ولا يستبدل التواصل البشري في القرارات الحساسة.

## أدوات التاجر

يمكن لاحقًا إضافة تحسين وصف المنتج، اقتراح عناوين وكلمات بحث، ضغط الصور، وإنشاء خلفية عرض مناسبة. يجب أن يراجع التاجر النص أو الصورة قبل نشرها، ولا يجوز للأداة اختلاق سعر أو كمية أو شهادة أو تقييم.

## حماية البيانات

لا ترسل محادثات المستخدم أو وثائق التاجر إلى خدمة خارجية قبل تحديد الغرض والموافقة وسياسة الاحتفاظ. تبقى هذه الميزة مخططًا مؤجلًا في النسخة الحالية، ولا توجد استدعاءات لخدمة ذكاء اصطناعي أو بيانات مستخدمين في الواجهة الثابتة.
