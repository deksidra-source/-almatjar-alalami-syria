Technical Requirement Document (TRD)
لتتمكن من إرفاقه مباشرة للذكاء الاصطناعي الخاص بالبرمجة أو للمبرمجين، بحيث يشمل كل جزئية وتفصيل تم النقاش عنه.
Document Requirement Document (TRD) - Syrian Marketplace Project
1. نظام إنشاء الحسابات والتعريف (Authentication & Onboarding)
إنشاء حساب الزبون:
التسجيل عبر رقم الهاتف المحمول المحلي مع رمز تفعيل (OTP) عبر SMS أو WhatsApp، أو البريد الإلكتروني.
تحديد الموقع الجغرافي:
تحديد المحافظة والمنطقة عند أول تسجيل لتخصيص عروض الشحن والمنتجات القريبة.
إنشاء حساب التاجر:
نموذج تقديم يتضمن (اسم المتجر، السجل التجاري أو الهوية شخصية، نوع المتجر: آليات أم استهلاكي، طرق استلام الأرباح المفضلة).
إدارة الجلسات:
استعادة الجلسة تلقائياً في حال إغلاق الهاتف أو انقطاع الكهرباء والبطارية دون فقدان البيانات.
2. تطبيق المستخدم (Customer Mobile App)
أ. واجهة التصفح والتبديل (Core UI Navigation)
زر التبديل الرئيسي (Toggle Switch):
مفتاح علوي مثبت في أعلى الشاشة للتحويل المباشر والكامل بين:
متجر الآليات والقطع الكبيرة
(قطع غيار، معدات ثقيلة، سيارات).
متجر البضائع الاستهلاكية
(ملابس، غذائيات، أدوات منزلية).
شريط البحث والفلترة:
فلترة الآليات:
حسب الماركة، سنة الصنع، الفئة، ورقم القطعة (OEM).
فلترة الاستهلاكات:
حسب اللون، القياس، العلامة التجارية، والسعر.
ب. ميزات الذكاء الاصطناعي المتقدمة (AI Capabilities)
المساعد الذكي "القط سنقر":
الشكل والتفاعل:
آيقونة عائمة على الشاشة لقط كرتوني بنظارات طبية. عند الضغط تفتح نافذة محادثة تفاعلية.
الوظيفة:
الإجابة عن استفسارات المنتجات، اقتراح التوافق لقطع السيارات، وتحويل البصمات الصوتية إلى عمليات بحث داخل التطبيق.
البحث البصري بالكاميرا (AI Visual Search):
تعرف الصور:
التقاط صورة للقطعة أو المنتج ومطابقتها فورياً مع قاعدة البيانات.
قارئ الأرقام (OCR):
مسح أرقام OEM المطبوعة على قطع الغيار وتحويلها لنص مجدول تلقائياً.
ج. قسم الفيديوهات القصيرة (Product Reels)
العرض:
قسم خاص داخل التطبيق لصفحة المنتجات يعرض فيديوهات قصيرة (15 - 30 ثانية).
ضوابط الأداء:
إلغاء التشغيل التلقائي (No Auto-Play)، وتعمل الفيديوهات عند الضغط فقط مع ضغط تلقائي للدقة إلى (480p/720p).
د. سلة التسوق وإتمام الطلب (Cart & Checkout)
سلة ذكية مجزأة:
تجميع المنتجات في السلة حسب كل تاجر تلقائياً لتوضيح تكلفة شحن كل متجر بشكل منفصل.
الفاتورة النهائية:
حساب (المجموع + تكاليف الشحن + الخصومات).
الدفع والتتبع:
خيارات الدفع عند الاستلام، المحافظ الإلكترونية، أو شركات الصرافة المحلية، مع نظام تتبع مباشر لحالة الطلب (معلق

3. لوحة تحكم التاجر (Vendor Dashboard)
أ. الشاشة الرئيسية والمنتجات
الرئيسية:
كروت إحصائية سريعة (مبيعات اليوم، الطلبات الجديدة، إجمالي المنتجات، الرصيد المتاح).
إضافة المنتجات:
حقول الآليات: رقم OEM، الموديلات المتوافقة، حالة القطعة (جديدة/مستعملة/مجددة).
حقول الاستهلاكات: الخيارات المتعددة (الألوان، المقاسات، تاريخ الصلاحية للغذائيات).
ب. مركز النمو والتحليلات (Growth Hub)
تحليلات الزيارات:
عدد مشاهدات المتجر، أوقات الذروة، وأكثر المنتجات زيارة.
تحليلات الأرباح:
رسم بياني للنمو، متوسط قيمة الطلب، ومعدل تحول الزوار إلى خيار الشراء (Conversion Rate).
سلوك المشترين:
المنتجات الأكثر إضافة للمفضلة أو السلة.
ج. إدارة الطلبات والمالية
الطلبات:
تحديث حالات الشحن، طباعة الفواتير، وبوالص الشحن بضغطة زر.
المحفظة:
متابعة صافي الأرباح بعد خصم عمولة المنصة، وتقديم طلبات سحب الأرباح مع تحديد طريقة الاستلام.
المحادثات:
صندوق رسائل مباشر مع الزبائن للاستفسارات الفنية.
4. لوحة تحكم الإدارة العامة (Super Admin Panel)
إدارة التجار والقبول:
مراجعة وثائق التجار الجديدة، اعتماد المتاجر أو حظرها، وتحديد نسبة العمولة الخاصة بكل تاجر أو فئة.
الإشراف على المحتوى (Content Moderation):
تدقيق الإعلانات والمنتجات والقطع المعروضة والفيديوهات قبل ظهورها للعلن لمنع الاحتيال.
المعاملات المالية:
إدارة المحافظ، الموافقة على طلبات سحب الأرباح للتجار، ومعاينة التقارير المالية الإجمالية للمنصة.
التسويق والإشعارات:
إدارة الواجهة الرئيسية، البانرات الإعلانية، كبونات الخصم، وإرسال الإشعارات الجماعية (Push Notifications).
الدعم والمستعمل:
قسم لمعالجة النزاعات بين المشترين والتجار وإدارة الشكاوى.
5. تحسينات شبكات الإنترنت والبيئة المحلية (Syrian Network Optimization)
ضغط الوسائط:
تحويل جميع الصور تلقائياً لصيغة 
WebP
بأقل من 
100KB
، وتقنيات ضغط الفيديوهات على السيرفر قبل النشر.
التحميل التدريجي (Lazy Loading):
لا يتم تحميل الصور إلا عند الوصول إليها أثناء التصفح.
العمل بدون إنترنت (Offline Mode):
اعتماد التخزين المحلي (SQLite/Realm) للحفاظ على بيانات السلة والصفحات الأخيرة عند انقطاع الإنترنت أو الكهرباء.
واجهات خفيفة:
تقليل المؤثرات الحركة (Animations) لدعم الهواتف القديمة وتوفير البيانات.
