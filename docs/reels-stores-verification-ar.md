# تحقق Reels والمتاجر

ظهرت نسخة Reels مع معاينة الفيديو، أزرار الإعجاب والتعليق والدخول إلى صفحة المتجر، وتقسيم المدة إلى 10 ثوانٍ و20 ثانية ودقيقة، مع أدوات التحرير والفلاتر والصوت.

ظهر زر الخطوط الثلاثة أعلى التطبيق، وفتح لوحة خمريّة تعرض مسارين واضحين: المتجر الصغير والمتجر الكبير. ظهرت للمتجر الصغير أقسام الغذائيات والألبسة والساعات والنظارات والقرطاسية وجميع الأقسام. وظهرت للمتجر الكبير أقسام السيارات وقطع الغيار والماكينات والخزانات والحاويات والمعدات الثقيلة وطلبات العرض.

الهوية المستخدمة في هذه الشاشة: الخمري للوحة الرئيسية، والأصفر للأزرار، والنصوص الداكنة داخل الأزرار الصفراء.

تم اجتياز فحص TypeScript بعد الإضافة.
