# دمج نسخة الويب الإنتاجية

أُضيفت نسخة WebDev الإنتاجية في مجلد `web-production/` دون حذف أو استبدال ملفات النسخة الأصلية في المستودع.

تحافظ النسخة على الشكل البصري الجديد المعتمد، وتضيف إليه البحث المتقدم، الدعم، البحث بالصورة، المساعد الذكي، والدخول المنفصل إلى لوحات المشتري والتاجر والمدير. قاعدة بيانات WebDev الحالية توسعت بإضافة جداول الدعم وطلبات البحث بالصورة فقط؛ الجداول السابقة للمتاجر والمنتجات والسلة والطلبات والدردشة وReels بقيت موجودة.

## اللوحات

- لوحة المشتري: الكتالوج، البحث، السلة، الطلبات، الدردشة، Reels.
- لوحة التاجر/البائع: فتح متجر صغير أو كبير، المنتجات، الطلبات، الدفع، الشحن والتسليم.
- لوحة المدير: سياسة الاشتراك، المراجعة، الدعم، التحليلات وإدارة الأسعار.

يختار المستخدم نوع اللوحة من شاشة الدخول، ثم يُعاد توجيهه إلى المساحة المناسبة بعد نجاح المصادقة.
