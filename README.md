# المتجر العالمي سوريا

مشروع مستقل لمنصة تجارة سورية متعددة البائعين، منفصل بالكامل عن مشروع «سوقنا سوريا». لا تشترك المشاريع في الملفات أو قاعدة البيانات أو أسرار البيئة أو النشر.

## محتويات المشروع

| المسار | الوظيفة |
|---|---|
| `frontend/` | واجهة المشتري والمتجر الصغير والمتجر الكبير ولوحة الإدارة وملفات CSS وJavaScript |
| `backend/` | خدمة Node.js، اتصال PostgreSQL، ترحيل المخطط، مسارات API والاختبارات |
| `mobile/` | تطبيق Flutter المستقل للمشتري والمتجر والترويج والحساب |
| `docs/` | الشروط والامتثال ومخطط قاعدة البيانات ودليل التشغيل وحدود الاستقلال |

## سياسة الإعلان المروّج

مدة الإعلان المروّج ثابتة على **7 أيام**. السعر المرجعي هو **1 دولار للمتجر الصغير** و**10 دولارات للمتجر الكبير**. الدفع اليدوي هو الخيار المفعّل حاليًا، بينما Sham Cash وiCash ظاهران كخيارات مؤجلة وغير مفعّلة. لا يحدث قبول أو تفعيل تلقائي؛ يراجع المدير الطلب ويقبل أو يرفض يدويًا.

## تشغيل المعاينة الثابتة

من مجلد المشروع:

```bash
cd frontend
python3 -m http.server 4173
```

ثم افتح `http://127.0.0.1:4173` في المتصفح.

## تشغيل الخلفية وقاعدة PostgreSQL

ادخل إلى `backend/`، انسخ `.env.example` إلى `.env`، ضع `DATABASE_URL` الخاص بقاعدة المشروع المستقلة، ثم شغّل:

```bash
npm install
npm run db:migrate
npm start
```

اختبر الخادم عبر:

```bash
curl http://localhost:4000/health
```

التفاصيل الكاملة موجودة في `docs/local-postgresql-node-setup-ar.md`.

## اختبار المشروع

```bash
node --check frontend/app.js
node backend/test/smoke-test.mjs
node --test backend/test/contracts.test.mjs
```

## Flutter

من مجلد `mobile/`:

```bash
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:4000
```

بناء iPhone وتوقيعه يحتاجان macOS وXcode وحساب Apple Developer.

## ما لا يجب رفعه إلى GitHub

لا ترفع ملفات `.env` أو كلمات مرور PostgreSQL أو مفاتيح JWT أو مفاتيح Sham Cash/iCash أو ملفات توقيع Android/iPhone مثل `.jks` و`key.properties` أو أي معلومات شخصية. ملف `.gitignore` الموجود في جذر المشروع يستبعد هذه الملفات تلقائيًا.

## حالة التنفيذ

الواجهة الأولية، مخطط PostgreSQL، خدمة Node.js الأولية، عميل Flutter، نظام الإعلان المروّج، وسياسة الدفع المؤجل موثقة ومختبرة بعقود محلية. ما يزال تفعيل المصادقة عبر SMS، تشغيل قاعدة الإنتاج، حسابات الدفع، والتوقيع والنشر في المتاجر يحتاج إعدادات وحسابات خارجية حقيقية.

لا تحتوي الحزمة على مراجعات أو تقييمات أو منتجات وهمية. لا تُضاف البيانات الحقيقية إلا عبر تدفقات المستخدم والتاجر بعد تفعيل الخلفية والصلاحيات.
